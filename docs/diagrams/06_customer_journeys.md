# Use Case Interaction Flows: Customer Journeys

![Customer Journeys](../charts/customer_journey_chart.png)

## Description
Sequence/customer-journey style diagram showing system steps and user touchpoints for:
- Product discovery (search, recommend, rerank)
- Customer support (query, escalate, resolve)
- Personalization (profile, recommend)
- Content ops (review process, generate description)
- Analytics (report, trends, KPIs)
Swim lanes differentiate customer, system, admin, MCP tools, and display decision/timing metrics for each step.
